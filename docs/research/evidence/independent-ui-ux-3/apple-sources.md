## Discrepancies with catalogue

- **Beta status is stale.** `TabRole.prominent` and every other 27.x symbol checked (`toolbarMinimizationBehavior`, `ToolbarOverflowMenu`, `visibilityPriority`, `topBarPinnedTrailing`, `toolbarMinimizationSafeAreaAdjustment`, `prominentTabIdentifier`, 27.1 `ArrangementView`) have no `beta` flag in DocC metadata. I read the JSON, not the rendered banner. DocC drives that banner from this flag, so I suspect the banner is gone.
- **Spelling.** SwiftUI ships `toolbarMinimizationBehavior(_:for:)` / `ToolbarMinimizationBehavior` (27.0). `toolbarMinimizeBehavior` has no doc page (404) but is what WWDC26 269 says at 7:36 and uses in the 7:37 snippet. Tab bars still use `tabBarMinimizeBehavior` (26.0). UIKit has the same split: session 278 at 11:32 says `barMinimizationBehavior` / `barMinimizationSafeAreaAdjustment`, docs have `UINavigationItem.navigationBarMinimization` of type `UIBarMinimization` (`minimizationBehavior`, `restorationBehavior`, `safeAreaAdjustment`).
- **Wrong timestamps:** M05 (14:54 is clear-glass conditions; flip guidance at 15:16), G06 (7:21 is an unrelated question; glass button style at 10:29-11:04), N02 (5:03-5:18), N07 (4:23-4:35), P04 (14:33-15:15; 13:31 is the chapter start), T07 (12:03; 10:52 is the chapter start, which opens with prominent tabs).
- T02: the Books avatar example is in wwdc2025/323 at 9:10, not on the `sharedBackgroundVisibility` page.
- T08: "Calendar" isn't in the 284 transcript. The dense-UI hard edge is stated without naming an app.
- M06: Notes isn't named on HIG Color. The light/dark/increased-contrast variant rule is on Adopting Liquid Glass.
- N04: the June 8, 2026 Sidebars change covers icon colors and the adaptable style. Content-beneath guidance is from June 9, 2025.
- A02: `accessibilityShowBorders` isn't new or macOS-only. It's available iOS 14+, macOS 11+, tvOS 14+, watchOS 7+, visionOS 1+, back-deployed before 26.1. Only the dedicated macOS setting is new in 27.
- A03: available from 26.4 on every platform, including tvOS, visionOS and watchOS.
- A05: Apple's wording is a Liquid Glass slider from "ultra clear to fully tinted" that adjusts tint. A rule that custom glass must follow it isn't documented.
- G06: the source is an informal group-lab answer. Adopting (Controls) and the badges sample are the citable sources for `.glass` button styles.
- S01-S06: HIG Search fields (June 8, 2026) states these as guidance. They should be classed Req, not only video examples.
- P02: partial/full-height inset-to-opaque isn't in the Sheets HIG (last changed March 24, 2026, button placement). It's in Adopting and wwdc2025/323.
- T04: HIG Toolbars says the system adds the overflow menu on macOS/iPadOS and "Don't add an overflow menu manually". That bears on a manual overflow menu.
- X03: Destination Video isn't on the cited Materials page.
- HIG Materials hasn't changed since September 9, 2025. The clear-glass and 35% wording is current, and no 27-era diffusion or edge refinements are documented there (they're only in SOTU 22:43-22:53).
- Landmarks sample pages now report `introducedAt 27.0` (Xcode 27).

## New cases

- **NC1: edge-to-edge sidebars on Mac and iPad (27).** "Sidebars expand to the edges on Mac and iPad… still refracting content", and icons "regain their color using your app's accent color… more clear which window is key". macOS windows also get a tighter corner radius. https://developer.apple.com/videos/play/wwdc2026/102/ 23:36-24:06. Ex (List/Label provide it automatically).
- **NC2: uniform top toolbar scroll edge (27).** "When content scrolls under floating bars, a uniform toolbar appears across the top." It's customizable with the existing scroll-edge APIs. wwdc2026/102 24:10-24:22; wwdc2026/278 11:50-12:21. Req.
- **NC3: opt-in iPhone sidebar (iOS 27).** `UITabBarController` `sidebar.preferredPlacement = .sidebar`. It's the app's choice, with no user toggle. The system decides by space, and `isAvailable` reports whether it's shown. wwdc2026/278 9:45-10:33. Ex/API.
- **NC4: prominent tab persists during collapse.** "The prominent tab is always visible, even when the tab bar collapses during scrolling." Any tab can be prominent via `prominentTabIdentifier` (iOS 27.0). wwdc2026/278 10:53-11:06; https://developer.apple.com/documentation/uikit/uitabbarcontroller/prominenttabidentifier. Req.
- **NC5: menu-bar icons hidden by default on iPadOS/macOS (27).** Opt in per item with `labelStyle(.titleAndIcon)` or `preferredImageVisibility`. wwdc2026/269 3:32-3:46 (snippet 3:34); wwdc2026/278 12:24-12:45; wwdc2026/102 24:27-24:40. Req.
