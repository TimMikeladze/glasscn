# Rules

Short, enforceable rules for anyone (human or agent) changing glasscn. Each file is one area; the tests named in them enforce what can be enforced.

- [design.md](design.md) — what glass is for, and when not to use it
- [components.md](components.md) — the API every component follows
- [tokens.md](tokens.md) — primitives, derived values, naming, safety
- [registry.md](registry.md) — items, files, dependencies, presets
- [accessibility.md](accessibility.md) — contrast, focus, motion, semantics
- [performance.md](performance.md) — what backdrop-filter costs and how to keep it cheap
- [native.md](native.md) — the React Native track and Liquid Glass
