- [registry.md](registry.md): items, files, dependencies, presets
- [accessibility.md](accessibility.md): contrast, focus, motion, semantics
- [performance.md](performance.md): what backdrop-filter costs and how to keep it cheap
- [native.md](native.md): the React Native track and Liquid Glass
